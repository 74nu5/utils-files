# Copilot Agent Mode Files

This directory contains mode files for GitHub Copilot Agents that define specialized workflows and contexts.

## Mode Types

- **Development Modes**: Different development workflows (TDD, debugging, refactoring)
- **Review Modes**: Code review and quality assurance contexts
- **Documentation Modes**: Technical writing and documentation generation

## Usage

Agent mode files help configure Copilot for specific development contexts and workflows, improving productivity and consistency.
