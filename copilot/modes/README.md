# Copilot Agent Mode Files

This directory contains **universal agent mode templates** for GitHub Copilot that define specialized workflows and contexts adaptable to any development methodology and technology stack.

## 🎯 Mode Types

- **Development Workflows**: TDD, debugging, refactoring - adaptable to any programming language
- **Review Processes**: Code review and quality assurance - configurable for any team standards  
- **Documentation Generation**: Technical writing - works with any documentation framework
- **Project Management**: User Story development, sprint planning - methodology-agnostic

## 🔧 Configuration Process

1. **Select** the appropriate mode template
2. **Configure** technology-specific variables:
   - `{TECH_STACK}` → Your programming language/framework
   - `{TESTING_FRAMEWORK}` → Your testing tools
   - `{PROJECT_METHODOLOGY}` → Agile, Scrum, Kanban, etc.
3. **Customize** workflows to match your team processes
4. **Remove** irrelevant sections for your use case

## 🌐 Universal Compatibility

These modes work across:
- **Any Programming Language** (C#, JavaScript, Python, Java, Go, etc.)
- **Any Framework** (React, .NET, Django, Spring Boot, etc.)
- **Any Methodology** (Agile, Waterfall, DevOps, etc.)
- **Any Team Size** (Solo developer to enterprise teams)
