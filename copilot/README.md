# GitHub Copilot Files

This directory contains **universal, technology-agnostic** files for GitHub Copilot that can be adapted to any development project.

## 🏗️ Structure

- **prompts/**: Universal prompts with configurable templates for any technology stack
- **instructions/**: Generic coding standards and best practices that can be customized for any programming language
- **modes/**: Flexible agent workflows adaptable to different development methodologies and project types

## 🚀 Usage

These files enhance your GitHub Copilot experience across **any technology stack**:

### 🔧 Configuration Steps
1. **Choose** the appropriate template file
2. **Replace** all variables marked with `{VARIABLE_NAME}` with your project-specific values
3. **Remove** sections that don't apply to your technology stack
4. **Add** technology-specific patterns and examples
5. **Save** the customized file for your project

### 🎯 Supported Use Cases
- **Web Applications** (React, Vue, Angular, Blazor, etc.)
- **Mobile Development** (Flutter, React Native, native iOS/Android)
- **Backend APIs** (REST, GraphQL, gRPC)
- **Desktop Applications** (.NET, Electron, Qt, etc.)
- **DevOps & Infrastructure** (Docker, Kubernetes, CI/CD)
- **Data Science & ML** (Python, R, Jupyter notebooks)
