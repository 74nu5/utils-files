# GitHub Copilot Files

This directory contains various files related to GitHub Copilot functionality.

## Structure

- **prompts/**: Custom prompts for GitHub Copilot
- **instructions/**: Copilot instruction files for specific behaviors and guidelines
- **modes/**: Copilot Agent mode files for different workflows and contexts

## Usage

These files can be used to enhance your GitHub Copilot experience by providing:
- Custom prompts for specific coding scenarios
- Instructions to guide Copilot's behavior
- Agent modes for specialized development workflows
