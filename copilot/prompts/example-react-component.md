# React Component Prompt

Create a functional React component with the following requirements:
- Use TypeScript for type safety
- Include proper props interface
- Add JSDoc comments for documentation
- Use modern React hooks (useState, useEffect if needed)
- Follow React best practices
- Include proper error handling
- Add accessibility attributes where appropriate
- Use CSS modules or styled-components for styling

## Example Usage

When creating a new React component, use this prompt to ensure consistent structure and best practices across your project.
