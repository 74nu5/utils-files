# Visual Studio Code Configurations

This directory contains Visual Studio Code configuration files and exports.

## File Types

- **settings.json**: User/workspace settings
- **extensions.json**: Recommended extensions
- **launch.json**: Debug configurations
- **tasks.json**: Task configurations
- **keybindings.json**: Custom keyboard shortcuts
- **snippets/**: Custom code snippets

## Usage

Import these configurations into VS Code to set up your development environment quickly and consistently.
