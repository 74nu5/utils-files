# JetBrains IDE Configurations

This directory contains configuration files for JetBrains IDEs (IntelliJ IDEA, WebStorm, PyCharm, etc.).

## File Types

- **settings.zip**: Exported IDE settings
- **live-templates/**: Custom live templates and code snippets
- **color-schemes/**: Custom color schemes and themes
- **code-styles/**: Code formatting and style configurations
- **keymap/**: Custom keyboard shortcuts and keymaps

## Usage

Import these configurations into your JetBrains IDE through File → Manage IDE Settings → Import Settings.
